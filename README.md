# Helixscreen Themes

A collection of custom themes for HelixScreen. This `main` branch serves as an index to the available theme branches.

## Available theme branches

- [Snapmaker_U1](https://github.com/Misunderstood-Wookiee/Helixscreen_Themes/tree/Snapmaker_U1) — Snapmaker U1 Stock and Fluidd Amber themes, along with HelixScreen layout changes. Compatible with Paxx12 Extended firmware.
