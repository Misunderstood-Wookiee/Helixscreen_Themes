# HelixScreen Themes

A collection of custom themes for HelixScreen, located in the `helixscreen/themes` folder.

This branch is for the Snapmaker U1.

These themes were generated with Claude AI.

End users are welcome to use the entire `helixscreen` folder, including its `themes` directory, if they wish to apply my HelixScreen layout changes.

## Available themes

- **Snapmaker U1 Stock** (`helixscreen/themes/snapmaker_u1_stock.json`) — a stock-inspired theme with familiar blue accents and complementary dark and light palettes.
- **Snapmaker U1 Fluidd Amber** (`helixscreen/themes/snapmaker_u1_fluidd_amber.json`) — a Fluidd-inspired theme with warm amber accents and coordinated dark and light palettes. This custom Amber theme is intended to be used directly alongside the [Snapmaker U1 Fluidd Theme](https://github.com/HZ-HanZone/Snapmaker-U1-Fluidd-Theme).

## Compatibility

All themes in this collection are compatible with the Paxx12 Extended firmware.
